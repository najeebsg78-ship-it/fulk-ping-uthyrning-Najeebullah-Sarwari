# fulk-ping-uthyrning-Najeebullah-Sarwari

Så startar man projektet:
1. klona repot
2. öppna mappen i intellij
3. projektet använder av JDK 25
4. Låt intellij läsa all Maven dependencies från pom.xml
5. Starta projektet genom att köra main metoden i UthyrningApplication.java
6. Öppna webbläsaren och gå till http://localhost:8080/swagger-ui/index.html för att se API-dokumentationen.


API anrop:
Get (getAll) - hämta alla uthyrningar
Get (getById) - hämta en uthyrning med ett specifikt id
Post (create) - skapa en ny uthyrning
Put (update) - uppdatera en befintlig uthyrning
Delete (delete) - ta bort en uthyrning med ett specifikt id
